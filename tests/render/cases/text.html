Text shaping and line layout

Static pages still depend on stable inline layout, line breaking, fallback, columns, and decoration. This fixture has no scripts, clocks, network requests, animations, or platform-generated content.

Every run uses identical markup and viewport geometry. Pixel comparisons therefore expose changes in style, layout, paint, raster, or font loading.

The compact column is intentionally justified so small shaping changes remain visible.
