# demo-hello

English · [简体中文](./README.zh.md)

Provides a minimal static HTML test fixture containing a title, paragraphs, and inline styles with zero subresources. Designed for quick smoke testing and pipeline verification.

## Usage

```bash
shotium hello.html --width 800 --height 600 -o hello.png
```

The multi-language demos now render [`apps/demo-card/card.html`](../demo-card/README.md) by default; this minimal fixture is retained for isolated testing and debugging.
